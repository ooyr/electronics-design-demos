# 电子设计竞赛硬件作品演示

本页面展示我参与电子设计竞赛时的硬件样机与演示视频。我主要负责 **PCB 设计、焊接调试与系统联调**，将电路方案落实为可运行、可测试的实物系统。

## 项目经历

- **2023 年单相逆变器**：以 TMS320F28335 DSP 为控制核心，硬件涉及 MOSFET 全桥、隔离驱动、辅助电源及 LC 滤波。我承担硬件设计、焊接调试与系统联调工作，项目获得电赛山西赛区二等奖。
- **2024 年单相 AC–AC 变换器并联系统**：采用 STM32F407，结合采样、隔离驱动、功率变换及滤波电路，实现交流输出调节与并联运行。我作为队长参与项目，主要负责 PCB 设计、焊接调试和软硬件联调，项目获得山西赛区一等奖、赛题组第一名。
